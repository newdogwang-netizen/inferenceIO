What the platform can prove

A model request, a tool request, a returned result and an independent transport observation are different facts. The UI keeps them separate and links each progress item to retained evidence.

The Codex chain contains 27 calls, 25 requested tools and 25 observed results. The Hermes view contains 61 calls, 67 observed results, 60 Hook observations and 20 other HTTP requests. These categories do not inflate one another.

Failures changed the implementation

PostgreSQL-safe views

Raw bodies stay immutable. Query projections replace only unsupported NUL characters and report the replacement count.

Terminal gap handling

Known body-chunk gaps now produce body_unavailable, not a permanently retrying normalization job.

Bounded pcap drainage

A 32 MiB memory-only queue separates tcpdump pipe reading from encrypted durable writes.

Multiple invocations

The workflow pairs and retains each capture, selecting a primary only with a clear fourfold duration lead.
